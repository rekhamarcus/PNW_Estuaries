This repository contains all code used for data download and analysis for my MSc research project, titled "Listening to the birds: supporting climate-informed estuary conservation planning in the Pacific Northwest". This project is focused on quantifying the effects of climate change on estuaries in the Pacific Northwest (Chapter 1) and incorporating this information into regional-scale bird conservation planning (Chapter 2). This project was carried out in collaboration with the Pacific Birds Habitat Joint Venture to support their regional-level decision making processes.

This respository is organized into the following folders:
1. Scripts: all R code scripts for data analysis, including download, wrangling, modelling, analysis, and figure creation.
2. Functions: R code for specific functions which served as part of the data analysis.
3. AHP: datasets used for the creation of estuary conservation assessments, including priority matrices obtained from AHP surveys
4. Figures: all figures generated for publication and sharing
5. Data: all cleaned data outputs used for the project

Details on the methodological approach as well as the background of this research can be found in the thesis (coming soon). Additionally, Chapter 1 has been published in the Journal of Environmental Management (link to come), and Chapter 2 is being prepared for publication.
